# xwang-ui

Shared React components and design tokens for the Xwang desktop applications.

```tsx
import "xwang-ui/styles.css"
import { Button, Card, Input } from "xwang-ui"
```

Install from a GitHub tag (下游都用 `#tag` 固定，升级时记得先删掉已安装副本再 `npm update`）：

```bash
npm install github:OWNER/xwang-ui#v0.6.0
```
